# AI Property Triage System

AI Property Triage System is a real-estate assistant project that helps analyze and improve property listings.

## Project Structure

- `webui/` - Streamlit user interface
- `services/` - backend services
- `n8n/` - automation workflow files
- `docs/` - project documentation

## Setup

Create a virtual environment and install dependencies:

```bash
python -m venv .venv
pip install -r webui/requirements.txt
